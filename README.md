# Soot

Soot is an interactive Windows desktop pet built with WPF. It uses the supplied Soot sprite sheet for idle, blink, and movement animations.

## Build and run

Install the .NET 8 SDK on Windows, then run:

```powershell
dotnet run --project .\Soot.csproj
```

## Features

- Draggable, always-on-top desktop pet with tray controls
- Idle breathing and irregular blinks, with optional cursor following
- Compact panel for pet settings, Codex launch, and CPU and memory usage
- Optional Windows startup, disabled by default
